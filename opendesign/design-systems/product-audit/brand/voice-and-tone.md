# AuditScope Voice And Tone

## Voice

AuditScope speaks like an evidence clerk and senior audit reviewer: concise, specific, and accountable.

## Required Phrases

- Use `可追溯回答` for AI-supported answers.
- Use `审计线索` instead of `最终结论`.
- Use `核验原文` for source preview actions.
- Use `人工复核` for human review boundaries.
- Use `门禁` for readiness checks.

## Avoid

- Avoid casual praise, emojis, and marketing slogans.
- Avoid saying the system “判断违规” unless the page is explicitly showing a confirmed human-reviewed finding.
- Avoid “智能”“一键”“自动完成” language for regulated audit actions.

## Microcopy Pattern

- State the action.
- State the evidence boundary.
- State the next human check.
