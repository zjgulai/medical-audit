# medical_audit 中文技术写作规则

本规则叠加于 Tech-Doc-Style-Chinese `v0.3.0`，固定上游提交为 `90ff8ccc07da5afc5ae00eb3516f9efa98bd572d`。上游检查器和许可证保存在 `tools/tech-doc-style-chinese/`，执行时不依赖网络或全局 Skill。

## 优先级

1. 保留事实、权限、安全边界、法律含义和失败条件。
2. 服从当前项目的产品基线和用户明确要求。
3. 保持命令、路径、API、字段、状态值和配置名原样。
4. 改善结构、术语、语气和排版。

不得为了语句更简短而删除适用范围、例外、恢复方式或证据等级。

## 项目术语

| 对象 | 首选写法 | 说明 |
|---|---|---|
| 产品 | AI 审计一体化协作平台 | 首次出现时使用；代码包名仍为 `medical_audit` |
| 用户界面 | Next.js 前端 | 不写成通用 SaaS 控制台 |
| 业务 API | FastAPI 后端 | 规范前缀为 `/api/v1` |
| 本地身份 | 角色模拟器 | 必须同时写明「仅本地测试」 |
| 生产访问模式 | `public-shell-readonly` | 只开放产品导览和公开运行元数据 |
| 证据等级 | L1、L2、L3、L4 | 等级必须同时说明副作用边界 |
| 生产业务状态 | `not_production_verified` | 本地通过不能替代生产结论 |

避免同时使用「AI 智能审计管理系统」「AuditScope」等旧名称描述当前产品。引用历史界面或代码字面量时可以保留原文，并注明历史来源。

## 事实、推断和不确定项

状态报告必须分为以下三类：

- `fact`：带命令、SHA、收据或页面观测的事实。
- `inference`：由多个事实推导的解释，必须说明推导依据。
- `uncertain`：尚未执行、证据过期或需要额外授权的项目。

时间敏感的状态必须写出 `observed_at`、Git SHA、证据等级、`production_side_effect` 和 `provider_call`。不得用「最新」「当前」替代这些字段。

## 操作步骤

操作文档按以下顺序编写：

1. 写明适用角色和前置条件。
2. 在危险动作之前写明风险和停止条件。
3. 每个编号步骤只包含一个主要动作。
4. 在步骤之后写明可观察的预期结果。
5. 写明失败恢复方式和不可自动恢复的边界。

生产命令必须区分只读检查、审计日志写入、业务写入、Provider 调用、部署和删除。一个授权不得推导为另一个授权。

## API 和错误文案

- 方法、路径、字段和值使用反引号。
- 接口说明包含前置条件、成功结果、失败结果和恢复方式。
- `401` 表示缺少受信身份上下文；`403` 表示身份存在但权限不足；`404` 可用于隐藏不可见资源；`409` 表示状态冲突；`422` 表示请求值无效；`503` 表示生产可信身份尚未启用或依赖不可用。
- 不把 `Success`、`Invalid` 或 `Bad Request` 机械翻译成界面文案。
- 错误提示说明发生了什么、影响是什么、如何恢复；不要泄露不可见对象是否存在。

## 命令、警告和恢复

命令使用带语言标识的代码块。占位符、输入和预期输出分开说明。警告必须位于风险动作之前，并写出对象、后果和是否可恢复。

删除、部署、回滚、生产写入和 Provider 调用必须提供：

- 精确目标。
- 当前 SHA 或对象身份。
- 允许的副作用。
- 停止条件。
- 恢复路径。
- 完成后的验证方法。

## 排版

- 中文正文使用全角标点；中文引号默认使用直角引号「」。
- 中文与英文、独立数字和版本号之间保留空格。
- 一篇文档只保留一个 H1，标题层级不得跳级。
- 一段只表达一个主要信息点；列表项保持同一层级。
- 不批量改写代码块、URL、JSON、API 路径、数据库字段或状态值。

## Frontmatter

受版本控制的 `docs/**/*.md` 和 `drafts/**/*.md` 至少包含：

```yaml
---
title: 文档标题
doc_type: 文档类型
module: 所属模块
status: active
created: YYYY-MM-DD
updated: YYYY-MM-DD
owner: self
source: human+ai
---
```

状态使用 `draft`、`active`、`stable`、`completed` 或 `superseded`。历史 handoff 和 backlog 在被新文档替代后使用 `superseded`，并链接权威入口。

## 校验与人工判断

```bash

```

`error` 阻断交付。`warning` 和 `style` 需要人工判断；不要为了消除提示而盲目替换合法术语、历史引用或机器可读内容。
