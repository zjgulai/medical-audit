# AI 审计一体化协作平台用户 Playbook

本文按 22 个功能域说明角色、前置条件、操作、副作用和恢复方法。候选的生产访问模式设计为 `public-shell-readonly`；除公开壳层外，业务能力均不得标记为生产已验证。2026 年 8 月 12 日的生产证据早于该候选，不能证明访问模式已经部署。

证据值只使用 `L3 shell pass`、`blocked_by_access_mode`、`not_production_verified`、`sample_only` 或 `not_run`。

## 1. 首页和访问边界

**适用角色**：匿名访客、全部本地测试角色。

**前置条件**：打开 `/`；生产构建变量为 `public-shell-readonly`。

**页面与 API**：页面 `/`；公开 API `/api/v1/health`、`/api/v1/deployment/metadata`。

**操作步骤**：

1. 打开首页。
2. 确认页面显示「登录暂未开放」或只读导览入口。
3. 打开只读产品导览。

**预期结果**：生产不建立伪会话，不加载业务数据；页面持续显示只读提示。

**副作用**：静态页面与公开 GET，无业务数据库写入。

**错误码**：受保护 API 返回 `503 trusted_identity_required`。

**恢复方法**：如果公开页面不可用，先检查 `/health` 和 release manifest；不要绕过门禁。

**已知限制**：可信登录尚未建设。

**本地证据**：Playwright 页面、健康和门禁单测通过。

**生产证据**：`L3 shell pass`；候选访问模式尚未部署。

## 2. 登录占位页与本地角色模拟

**适用角色**：匿名访客；本地开发人员。

**前置条件**：生产访问 `/login`；本地以 `header-transition-test` 启动。

**页面与 API**：页面 `/login`；本地 API `/api/v1/auth/session`、`/api/v1/auth/roles`。

**操作步骤**：

1. 在生产打开 `/login`，确认只显示登录未开放说明。
2. 在本地选择 `member`、`director`、`technician` 或 `admin`。
3. 进入对应工作台并检查权限按钮。

**预期结果**：生产没有角色切换；本地角色模拟器明确标记「仅本地测试」。

**副作用**：本地可能写浏览器 LocalStorage；生产无身份写入。

**错误码**：生产业务请求返回 `503`；本地缺租户上下文时可返回 `401`。

**恢复方法**：清除本地模拟状态后重新选择角色；生产等待 SSO/OIDC。

**已知限制**：Header 和 LocalStorage 不能作为可信身份。

**本地证据**：角色和权限单测、登录视觉 E2E 通过。

**生产证据**：`blocked_by_access_mode`。

## 3. 医疗审计及疑点定位

**适用角色**：成员、主任。

**前置条件**：用户属于疑点所在项目；本地存在可见疑点。

**页面与 API**：页面 `/medical-audit`；API `/api/v1/audit-findings`、`/api/v1/audit-findings/{finding_key}/review-status`。

**操作步骤**：

1. 从工作台选择「进入复核」，或打开 `/medical-audit?finding=<finding_key>`。
2. 等待疑点列表加载。
3. 核对目标疑点已选中；当前筛选器会自动调整，避免隐藏目标。
4. 更新复核状态或创建复核任务。

**预期结果**：仅定位可见疑点。无效、不可见或已删除 ID 均显示「未找到可见疑点」。

生产只读壳层不加载疑点、任务或报告数据，也不显示新建、导入、复核、补充材料或生成报告控件。

**副作用**：查看列表无业务写入；状态和任务操作写入疑点、任务及审计记录。

**错误码**：不可见资源返回 `404`；无权限返回 `403`；状态冲突返回 `409`。

**恢复方法**：返回全部疑点，清除筛选条件并重新定位；不要根据错误文案推断不可见对象是否存在。

**已知限制**：生产业务疑点被访问模式阻断。

**本地证据**：深链、筛选、无效 ID 和页面交互测试通过。

**生产证据**：`blocked_by_access_mode`。

## 4. 基金合规

**适用角色**：成员、主任。

**前置条件**：本地已有审计项目或样例导览数据。

**页面与 API**：页面 `/fund-compliance`；关联 `/api/v1/audit-findings` 和项目 API。

**操作步骤**：

1. 打开基金合规专题。
2. 查看复核表单、费用表单和归档入口。
3. 选择「进入医保审计」继续处理疑点。

**预期结果**：页面展示基金审计入口，不把 Sample 数据描述为生产结果。

**副作用**：页面导航无业务写入；后续疑点操作按对应功能记录副作用。

**错误码**：业务 API 被生产门禁阻断时返回 `503`。

**恢复方法**：使用页面导览；需要真实数据时回到本地或等待可信身份启用。

**已知限制**：真实 HIS 数据未在本轮接入验收。

**本地证据**：页面合同和 CTA E2E 通过。

**生产证据**：`L3 shell pass`。

## 5. 基金复核

**适用角色**：成员、主任。

**前置条件**：打开基金专题；准备费用汇总、分类汇总或就诊明细数据。

**页面与 API**：页面 `/fund-compliance/review`；后续分析使用 `/api/v1/analytics/table-upload`。

**操作步骤**：

1. 打开复核表单。
2. 切换「费用汇总表」「分类汇总表」和「就诊明细表」。
3. 选择「进入分析」后上传本地测试数据。

**预期结果**：表单标签和分析模板一致，路由保留模板参数。

**副作用**：切换表单无写入；上传会写文件和分析历史。

**错误码**：文件无效返回 `422`；生产上传返回 `503`。

**恢复方法**：核对文件格式和模板；上传失败时不要重复提交未知状态请求。

**已知限制**：生产写入和真实医院数据未验证。

**本地证据**：表单、导航和分析入口 E2E 通过。

**生产证据**：`blocked_by_access_mode`。

## 6. 智能助手、会话和模型选择

**适用角色**：全部本地测试角色。

**前置条件**：本地 Fake 模型目录可用；选择知识库或智能体。

**页面与 API**：页面 `/chat`；API `/api/v1/query/models`、`/api/v1/query`、`/api/v1/chat/attachments/analyze`。

**操作步骤**：

1. 本地选择模型。
2. 选择一个或多个知识来源。
3. 使用 `@` 选择智能体。
4. 可选上传测试附件。
5. 输入问题并发送。
6. 在生产只读壳层确认页面只显示能力说明，不显示输入、上传、知识来源、智能体、模型或发送控件。

**预期结果**：本地回答带引用，模型、知识库和智能体选择写入请求合同。生产只读壳层不请求模型、来源或会话 API。

**副作用**：查询可能写历史和审计日志；附件产生文件记录；真实 Provider 调用需单独授权。

**错误码**：模型不可用或 Provider 失败返回受控错误；生产返回 `503`。

**恢复方法**：改用可用模型或确定性 Fake Provider；不要在未知执行状态下重复付费调用。

**已知限制**：真实 LLM Provider 冒烟为 `not_run`。

**本地证据**：模型、来源、智能体、附件和查询 E2E 通过。

**生产证据**：`blocked_by_access_mode`；候选尚未部署。

## 7. 智能体

**适用角色**：具备 `MANAGE_AGENTS` 的角色。

**前置条件**：本地 Agent Store 可用。

**页面与 API**：页面 `/agents`；API `/api/v1/agents`、`/api/v1/agents/{agent_key}/prompt-versions`、调用和反馈接口。

**操作步骤**：

1. 打开「我的智能体」。
2. 查看详情和当前 Prompt 版本。
3. 在允许时创建版本、提交评审、回滚或调用。

**预期结果**：目录显示服务端数据；版本和生命周期遵守服务端门禁。

**副作用**：创建、版本、评审、回滚、调用和反馈均写入 Store 或日志。

**错误码**：无权限返回 `403`；状态冲突返回 `409`；生产返回 `503`。

**恢复方法**：刷新智能体状态；回滚前核对目标版本，不要覆盖历史版本。

**已知限制**：编辑、删除和知识配置仍有 Preview 边界。

**本地证据**：目录、详情和本地调用页面测试通过。

**生产证据**：`not_production_verified`。

## 8. 智能体市场

**适用角色**：具备 `MANAGE_AGENTS` 的角色。

**前置条件**：市场目录可读；本地允许安装。

**页面与 API**：页面 `/agent-market`；API `/api/v1/agent-market/catalog`、`/api/v1/agent-market/templates/{template_id}/install`。

**操作步骤**：

1. 浏览分类和模板详情。
2. 核对模板用途和权限。
3. 在本地选择安装。

**预期结果**：目录加载失败时显示失败状态，不回退成伪生产数据。

**副作用**：浏览无业务写入；安装创建智能体记录。

**错误码**：无权限返回 `403`；生产安装返回 `503`。

**恢复方法**：刷新目录；安装失败时先查询现有智能体，避免重复安装。

**已知限制**：生产安装未验证。

**本地证据**：目录和详情 E2E 通过。

**生产证据**：`L3 shell pass`。

## 9. 分析看板

**适用角色**：具备 `ANALYZE_DATA` 的角色。

**前置条件**：准备脱敏 CSV 或 Excel 测试文件。

**页面与 API**：页面 `/analytics`；API `/api/v1/analytics/table-upload`、`/api/v1/analytics/table-uploads`。

**操作步骤**：

1. 本地选择审计案例或分析模板。
2. 上传文件。
3. 查看分析结果和历史记录。
4. 在生产只读壳层确认没有示例上传、文件上传、刷新、重试或历史加载请求。

**预期结果**：本地文件来源、分析状态和历史可追踪，Fake 分析不得冒充 Provider 结果。生产只读壳层只提供能力导览。

**副作用**：上传文件并写分析历史；可能调用 Provider。

**错误码**：文件格式或内容无效返回 `422`；生产返回 `503`。

**恢复方法**：使用支持的脱敏文件重试；检查历史后再决定是否重复提交。

**已知限制**：真实医院数据和 Provider 未验证。

**本地证据**：页面和上传入口 E2E 通过。

**生产证据**：`blocked_by_access_mode`；候选尚未部署。

## 10. 项目、成员和文件

**适用角色**：成员、主任、管理员；成员管理需要相应权限。

**前置条件**：本地 Project Store 可用；选择可见项目。

**页面与 API**：页面 `/projects`；API `/api/v1/projects`、`/api/v1/projects/{project_key}/members`、文件和 dashboard 接口。

**操作步骤**：

1. 浏览可见项目并选择项目。
2. 查看或维护成员。
3. 上传项目文件并执行治理复核。
4. 打开项目驾驶舱。

**预期结果**：项目、成员、文件和 dashboard 使用同一 `project_key`；不可见项目不泄露存在性。

**副作用**：创建项目、成员和文件会写 Store、文件及审计日志。

**错误码**：不可见项目返回 `404`；权限不足返回 `403`；重复身份返回 `409`。

**恢复方法**：核对项目成员资格；上传失败时查询文件列表确认是否已创建。

**已知限制**：生产业务项目被访问模式阻断。

**本地证据**：项目创建、成员、文件、可见性和页面测试通过。

**生产证据**：`blocked_by_access_mode`。

## 11. 审计驾驶舱

**适用角色**：可见项目成员和管理员。

**前置条件**：至少存在一个可见项目。

**页面与 API**：页面 `/audit-cockpit`；API `/api/v1/projects/{project_key}/dashboard`。

**操作步骤**：

1. 选择当前项目。
2. 查看阶段、风险、证据状态、待办和项目动态。
3. 选择「项目管理」返回项目页。

**预期结果**：无可见项目时显示明确空状态；失败时不显示固定指标冒充真实数据。

**副作用**：读取 dashboard；可能产生访问审计日志。

**错误码**：项目不可见返回 `404`；生产返回 `503`。

**恢复方法**：加入项目或切换可见项目；Store 失败时停止依赖页面指标。

**已知限制**：生产数据不可读。

**本地证据**：驾驶舱、项目入口和导航 E2E 通过。

**生产证据**：`L3 shell pass`。

## 12. 文档检索和个人资料

**适用角色**：全部本地测试角色；跨用户读取需额外权限。

**前置条件**：本地文档目录和检索索引可用。

**页面与 API**：页面 `/documents`；API `/api/v1/documents/library`、`/api/v1/documents/search`、上传、下载和治理接口。

**操作步骤**：

1. 选择来源或输入关键词。
2. 执行搜索。
3. 打开命中位置或下载原文。
4. 在本地上传个人或项目文档，并按治理状态处理。

**预期结果**：结果显示来源、定位和 provenance；下载按权限控制。

**副作用**：搜索可能写查询历史；上传写文件和治理记录；下载为读取。

**错误码**：无权限返回 `403`；不可见文档返回 `404`；文件无效返回 `422`。

**恢复方法**：缩小来源范围或修正关键词；上传失败时查询上传列表。

**已知限制**：外部 DLP 和生产文档 UAT 未完成。

**本地证据**：目录、搜索、预览和下载控件 E2E 通过。

**生产证据**：`blocked_by_access_mode`。

## 13. OCR

**适用角色**：具备文档或分析权限的本地用户。

**前置条件**：本地 Fake OCR 或明确授权的 OCR Provider 可用。

**页面与 API**：页面 `/ocr`；API `/api/v1/ocr/capabilities`、`/api/v1/ocr/extract`。

**操作步骤**：

1. 本地查看 OCR capability。
2. 上传支持的扫描文件。
3. 启动文本识别。
4. 核对页数、文本和错误页。
5. 在生产只读壳层确认没有 capability 请求、文件选择或「开始文本识别」控件。

**预期结果**：本地能力不可用时禁止启动，结果区分 Fake 与真实 Provider。生产只读壳层只显示能力说明。

**副作用**：上传临时文件；真实 OCR 可能产生 Provider 调用和费用。

**错误码**：能力未就绪或生产门禁返回 `503`；输入无效返回 `422`。

**恢复方法**：核对文件类型、页数和大小；真实调用失败时保留 job 状态后再决定重试。

**已知限制**：本轮真实 OCR 为 `not_run`。

**本地证据**：页面和 capability 合同测试通过。

**生产证据**：`blocked_by_access_mode`；候选尚未部署。

## 17. 报告、底稿、草稿、签发和导出

**适用角色**：成员可创建草稿；仅主任可签发。

**前置条件**：任务对当前项目可见；报告构建门禁通过；任务未关闭且未签发。

**页面与 API**：页面 `/reports`；API `/api/v1/reports/workpaper-templates`、`/api/v1/reports/drafts`、`/api/v1/reports/drafts/{task_id}/signoff` 和导出接口。

**操作步骤**：

1. 选择项目和交付物。
2. 创建或预览报告草稿。
3. 核对 `can_sign`、`gate_ready` 和 `writes_allowed`。
4. 主任在三项均为 `true` 时签发。
5. 下载 DOCX、Markdown 或 JSON 交付物。

**预期结果**：成员、技术人员和管理员看不到签发按钮；重复签发被拒绝。两个并发签发请求只允许一个返回 `200`，另一个返回 `409`，并且只写一条签发操作日志。

**副作用**：草稿和签发写任务、报告及审计日志；下载为读取。

**错误码**：不可见任务 `404`；无权限 `403`；门禁、重复签发或关闭态 `409`。

**恢复方法**：修复报告门禁后刷新工作台；签发状态未知时先查询任务，不要重复提交。

**已知限制**：生产签发和导出未执行。

**本地证据**：角色、可见性、构建门禁、重复签发、并发签发和关闭态测试通过。

**生产证据**：`not_production_verified`。

## 18. 整改、附件和状态迁移

**适用角色**：成员提交整改；主任验收和关闭。

**前置条件**：创建请求提供可见 `project_key`；持久化 Store 可用。

**页面与 API**：页面 `/remediation`；API `/api/v1/remediation/workbench`、`/api/v1/remediation/items`、状态和附件接口。

**操作步骤**：

1. 创建整改项并保存响应中的 UUID `id`。
2. 成员依次迁移到 `in-rectification` 和 `pending-acceptance`。
3. 使用真实 UUID 上传补证附件。
4. 主任选择 `accepted` 或 `rejected`。
5. 若通过，主任从 `accepted` 迁移到 `closed`。

**预期结果**：前端只显示 `allowed_transitions`；Sample 模式无写按钮；关闭后不可上传或改状态。两个基于同一旧状态的并发更新只允许一个提交，过期请求返回 `409`。

**副作用**：创建、状态、附件和关闭均写入 Store、文件和审计日志。

**错误码**：非法状态 `422`；非法迁移或关闭态 `409`；权限不足 `403`；不可见资源 `404`。

**恢复方法**：刷新服务端状态；被退回后从 `rejected` 进入 `in-rectification`。遗留无项目记录保持只读。

**已知限制**：生产整改业务未验证。

**本地证据**：UUID、空库、Sample、项目可见性、状态机、并发冲突、附件和关闭态测试通过。

**生产证据**：`not_production_verified`。
