# 采购与销售（买卖）合同专项审查 + 财务税务审计要点

> **定位**：contract-audit skill 专项参考。采购/销售/买卖类合同必读；任何含价款、发票条款的合同也需加载其中财税部分。
> **法域**：中华人民共和国。以《民法典》合同编第九章「买卖合同」（第595–647条）为核心。
> **使用方式**：清单化逐项核查，命中即提示风险并给出依据。每项给出「审查什么 / 常见风险 / 法律依据」。
> **风险标记**：【效力】影响合同或条款效力；【高危】实务高发争议/损失；【程序】程序性瑕疵；【税务】涉税风险；【舞弊】舞弊信号；【提示】优化建议。
> **版本提示**（引用前请注意时效）：
> - 《中华人民共和国增值税法》2024-12-25 公布，**2026-01-01 起施行**，取代《增值税暂行条例》（本稿引增值税法条号）；
> - 《保障中小企业款项支付条例》经国务院令第802号修订，**2025-06-01 起施行**（原国务院令第728号）；
> - 国资委贸易「十不准」（国资发财评规〔2023〕74号）**仅直接适用于中央企业**，地方国企参照执行。
> **纪律**：条文号不确定时只写制度名称，不编造文号。

## 第一部分 采购/销售（买卖）合同专项审查清单

### 1.1 标的物与规格条款

- [ ] **标的物描述的唯一性**【高危】
  - 审查什么：品名、型号、规格、等级、生产厂家、产地、执行标准（国标GB/行标/企标编号）是否完整到「足以唯一识别」，能否排除替代交付。
  - 常见风险：只写「钢材一批」「电脑100台」无型号规格 → 卖方低配交付、以次充好，买方举证困难；进口设备未注明产地/品牌/序列号规则；通用名与商标名混用。
  - 法律依据：《民法典》第596条（买卖合同内容一般包括标的物名称、数量、质量、价款、履行期限地点方式、包装、检验标准和方法、结算方式等条款）；第510–511条（约定不明时的补充与补缺规则，其中质量要求不明时按强制性国家标准→推荐性国家标准→行业标准→通常标准或合同目的特定标准履行）。
- [ ] **技术规格附件的效力与优先级**
  - 审查什么：技术协议、图纸、样品、招投标技术参数表是否列为合同附件；附件与正文冲突时何者优先；变更技术参数的程序（书面变更单）。
  - 常见风险：技术协议仅商务人员签字未盖章、未注明日期版本；招标文件承诺参数与合同正文不一致且无优先顺序条款 → 验收争议。
  - 法律依据：《民法典》第470条（合同一般条款）、第466条（合同条款争议的解释规则）。
- [ ] **凭样品买卖的样品封存**（如适用）
  - 审查什么：是否封存样品并双方签封、是否对样品质量作文字说明、隐蔽瑕疵处理。
  - 常见风险：样品未封存或未注明封存日期 → 交付物与样品是否一致无法证明；样品本身有隐蔽瑕疵的，交付物仍须符合同种物通常标准。
  - 法律依据：《民法典》第635条（交付标的物应与样品及其说明质量相同）、第636条（样品隐蔽瑕疵规则）。
- [ ] **数量与计量条款**
  - 审查什么：计量单位明确（吨/公斤/件/套）、溢短装条款（±%）及价款结算口径、以何种计量凭证为准（卖方发货磅单/买方入库磅单/第三方公估）、途耗承担。
  - 常见风险：大宗散装货物未约定计量依据与合理途耗 → 数量短少争议；溢短装未约定按实结算还是按合同量结算。
  - 法律依据：《民法典》第596条；第511条（约定不明补缺）。

### 1.2 所有权与风险转移（《民法典》第604–611条）

> 核心规则：我国采**交付主义**——风险原则上随交付转移，**与所有权转移分离**；当事人可另行约定。审查重点是合同是否把「风险转移时点」「所有权转移时点」「验收合格时点」三者混为一谈。

- [ ] **风险转移时点是否明确约定**【高危】
  - 审查什么：是否写明风险自何时转移（交付时/验收合格时/安装调试完成时）。未约定的，默认交付时转移。
  - 常见风险：仅写「货到现场」未写风险转移 → 运输途中毁损按法定规则处理，与当事人预期不符；设备类合同买方希望风险在验收合格后转移，但合同沉默 → 交付即转移。
  - 法律依据：《民法典》第604条（交付前出卖人承担、交付后买受人承担，法律另有规定或当事人另有约定除外）。
- [ ] **需要运输的标的物的风险规则匹配**
  - 审查什么：约定交付地点为买方指定地点并代办托运的，货交承运人后风险归买方；未约定交付地点且需运输的，货交**第一承运人**后风险归买方。
  - 常见风险：卖方代办托运但买方误以为卖方承担全程风险；贸易术语（FOB/CIF/DAP 等 Incoterms）与合同法定规则表述冲突、未注明术语版本（如 Incoterms® 2020）。
  - 法律依据：《民法典》第607条；第603条（交付地点的确定）。
- [ ] **在途货物买卖的风险**
  - 审查什么：出卖人转卖已交承运人运输的在途货物，除另有约定外，风险自**合同成立时**起由买受人承担。
  - 常见风险：买方受让在途货物后货物在到港前灭失仍须付款；未核查提单、保险单背书转让安排。
  - 法律依据：《民法典》第606条。
- [ ] **买方违约迟延受领时的风险提前转移**
  - 审查什么：因买方原因未按期交付/买方违反约定不收取的，风险自违约时起由买方承担。
  - 常见风险：买方无正当理由拒收或拖延提货，货在卖方仓库灭失仍须付款；合同未约定买方收货时限与逾期后果。
  - 法律依据：《民法典》第605条、第608条。
- [ ] **单证未交付不影响风险转移**
  - 审查什么：卖方未按约交付提单、质检单等单证资料的，不影响风险转移（但可主张违约责任）。
  - 常见风险：买方以「单证未齐」主张风险未转移、拒付货款，法院不支持。
  - 法律依据：《民法典》第609条、第611条。
- [ ] **质量根本不符时的风险回转**
  - 审查什么：标的物不符合质量要求致合同目的不能实现的，买方可拒收或解除，风险由卖方承担。
  - 法律依据：《民法典》第610条。
- [ ] **所有权转移与保留所有权安排**【高危】
  - 审查什么：动产所有权一般自交付时转移（《民法典》第224条）；卖方是否约定**所有权保留**（未付清价款前所有权归卖方）；保留所有权是否**办理登记**——未经登记不得对抗善意第三人。
  - 常见风险：买方破产时卖方未登记所有权保留 → 标的物被纳入破产财产；买方已转售给善意第三人 → 卖方取回权落空。买方视角：付清全款前应限制对设备的处分、抵押。
  - 法律依据：《民法典》第224条、第641条（保留所有权，未经登记不得对抗善意第三人）、第642条（出卖人取回权情形）、第643条（回赎与转卖）。
- [ ] **权利瑕疵担保**
  - 审查什么：卖方保证第三人对标的物不享有任何权利；买方缔约时明知有权利负担的除外。
  - 常见风险：标的物已被抵押/质押/被司法查封仍出售；二手设备附带融资租赁登记未注销（核查「动产融资统一登记公示系统」）。
  - 法律依据：《民法典》第612条、第613条；第597条（出卖人未取得处分权致所有权不能转移的，买受人可解除并主张违约责任）。

### 1.3 质量验收与异议期（《民法典》第620–624条）

- [ ] **检验期限是否约定且合理**【高危】
  - 审查什么：是否约定明确检验期限（到货后X日内）；期限长短与标的物性质是否匹配（外观瑕疵可短、需安装调试/隐蔽瑕疵应长或区分设置）。
  - 常见风险：检验期约定过短（如「货到3日内验收否则视为合格」）→ 依《民法典》第622条，该期限仅视为对**外观瑕疵**的异议期，隐蔽瑕疵不受限——卖方不可误以为短条款能一劳永逸；买方不可因条款短就放弃及时检验。
  - 法律依据：《民法典》第620条（约定检验期内检验，未约定的应及时检验）、第622条（检验期过短仅视为外观瑕疵异议期；约定检验期/质保期短于法律法规规定期限的，以法定为准）。
- [ ] **异议通知义务与失权后果**
  - 审查什么：约定检验期的，买方须在该期限内将数量/质量不符情形**通知**卖方，怠于通知视为符合约定；未约定检验期的，应在发现或应发现的合理期限内通知，最长不超过收货之日起**2年**（有质保期的适用质保期，不适用2年）；卖方明知不符的，买方不受通知期限限制。
  - 常见风险：买方收货后未及时检验/未书面留痕通知 → 丧失质量抗辩权，仍须付全款；口头异议无证据。
  - 法律依据：《民法典》第621条；《买卖合同解释》第12条（「合理期限」综合认定因素；2年为最长不变期间，不适用时效中止中断）、第14条（期限经过后主张不符不予支持）。
- [ ] **签收≠验收条款**
  - 审查什么：是否写明签收单/入库单仅证明数量与外观收货，不构成质量验收合格；验收以验收报告/验收单签署为准。
  - 常见风险：收货人员在送货单上签「验收合格」→ 被认定放弃异议；司法实践一般认为签收仅属外观、数量检查（参考（2017）最高法民申1114号裁判观点），但单据上印有「验收合格」字样仍会制造败诉风险。
  - 法律依据：《民法典》第620条体系解释；《买卖合同解释》第13条（买受人付款、确认欠款、使用标的物不当然视为放弃异议，但另有约定除外）。
- [ ] **验收标准、方法与程序**【高危】
  - 审查什么：验收依据（合同约定标准/国家标准/封样）；检验机构与费用承担（第三方检测谁委托、谁付费、不合格时费用转由责任方承担）；初验/终验/试运行验收的分层（设备类：到货验收→安装调试验收→试运行验收→最终验收）；验收不合格的处置（修理、更换、退货、减价、整改期限与复验程序）。
  - 常见风险：只写「按国家标准验收」未指明标准号；未约定复验与争议鉴定机制 → 质量僵局；未约定整改期与视为验收合格/不合格的默示规则。附带服务义务（安装调试、操作培训、资料交付）只写「负责」未写标准（验收基准、培训人数/时长/考核方式、技术资料清单）→ 履约完毕与否无从认定。
  - 法律依据：《民法典》第596条、第615条（按约定质量要求交付）、第616条（质量要求不明补缺）、第617–618条（质量不符的违约责任与瑕疵减轻）。
- [ ] **质保期（质量保证期）与检验期的衔接**
  - 审查什么：质保期起算点（验收合格之日/交付之日/发票之日——差异巨大）、质保范围（整机/主要部件/易损件除外）、质保期内卖方的响应时限与费用（上门、备件、人工谁承担）、质保期与2年异议期关系（有约质保期从质保期）。
  - 常见风险：质保期自「发货之日」起算 + 长运输安装周期 → 实际可用质保期严重缩水；易损易耗件排除清单过宽；「接通知后X小时响应」未定义「响应」（远程答复/到场/完成修复）及未兑现的违约责任 → 时限无约束力。
  - 法律依据：《民法典》第621条第2款（有质量保证期的适用质保期）。
- [ ] **三包义务（消费品目录商品）**
  - 审查什么：列入《实施三包的部分商品目录》的商品，销售者法定三包义务不因合同约定而免除：售出7日内性能故障可退/换/修；15日内可换/修；三包有效期内修理两次仍不能正常使用可换或退；三包有效期自开具发票之日起算，扣除修理占用与待修时间；生产者停产后5年内保证零配件供应。
  - 常见风险：B2B 合同中经销商向下游转嫁三包责任无追索安排；合同约定「售出一概不退」等排除法定三包义务的条款无效风险。
  - 法律依据：《部分商品修理更换退货责任规定》（国家三包规定）第8–13条；《消费者权益保护法》第24条（B2C 场景）。
- [ ] **知识产权担保（《民法典》第600条）**【高危】
  - 审查什么：出卖具有知识产权的标的物（软件、设备含嵌入式软件、技术产品），除法律另有规定或另有约定外，知识产权**不随买卖转移**给买方；买方需要的不只是所有权，还应核查许可范围（使用、复制、转售、二次开发权）。
  - 常见风险：买方购入设备/软件后误以为可自由复制、OEM 贴牌转售 → 侵权；合同未约定卖方对第三方知识产权侵权主张的担保与抗辩协助义务（如产品被诉专利侵权时卖方的赔偿与替换义务）。
  - 法律依据：《民法典》第600条；第612条（权利瑕疵担保）；建议参照《民法典》技术合同章与《专利法》《著作权法》侵权责任规则约定第三方索赔处理机制。
- [ ] **知识产权瑕疵的约定担保条款**
  - 审查什么：是否约定卖方担保交付物不侵犯第三方知识产权；侵权索赔时的处理（卖方负责应诉、赔偿、更换或退货）；买方按卖方图纸/规格定制时侵权责任的分担（买方指定导致的侵权一般由买方承担，应明示）。
  - 法律依据：《民法典》第600条、第612条；约定优先。

### 1.4 交付、运输与分批交付

- [ ] **交付时间与期限表述**
  - 审查什么：明确交付日期或期限（「X年X月X日前」而非「尽快」「收到预付款后适时」）；分批交付的每批时间表；卖方在交付期限内可任一时点交付的默认规则是否被修改；迟延交付违约金（日万分之X）与累计上限、解除触发天数。
  - 常见风险：交付期与预付款支付、原材料采购周期脱钩未写前提；未约定迟延交付的催告与解除权 → 只能证明实际损失索赔。
  - 法律依据：《民法典》第601条（按约定时间交付，约定交付期限的可在期限内任何时间交付）、第602条（期限不明补缺至第510条、第511条第4项——债权人可随时要求履行但应给对方必要准备时间）。
- [ ] **交付地点与方式**
  - 审查什么：交付地点明确到门牌/仓库；送货（卖方送）/提货（买方自提）/代办托运；未约定或不明时的法定补缺：需运输的交第一承运人；不需运输的在订立合同时双方知道的标的物所在地交付，不知道的在卖方订立合同时营业地交付。
  - 常见风险：交付地点既决定风险转移又决定运输费与保险责任，却写成「另行协商」。
  - 法律依据：《民法典》第603条、第607条。
- [ ] **运输责任、保险与包装**【高危】
  - 审查什么：运费、装卸费、保险费承担；运输方式与承运人选择权；易损/危化品的包装标准与标志（包装不符致损的责任）；货运保险投保义务与受益人；交付凭证（送货单、物流单、签收单）样式与签收人授权范围。
  - 常见风险：未约定包装标准，货物受潮/破损责任不清；买方临时员工/保安签收被认定为有效签收。
  - 法律依据：《民法典》第596条（包装方式条款）、第606–607条（风险规则）、第619条（按约定包装方式交付，不明时按通用方式/足以保护标的物且节约资源环保的方式）。
- [ ] **分批交付（分批履行）解除规则**
  - 审查什么：分批交付合同任一批违约对整体的影响：一批不交付或交付不符致该批不能实现合同目的的，可就该批解除；致之后各批不能实现合同目的的，可就该批及之后各批解除；各批相互依存的（如成套设备分批发），可就已交付和未交付的全部解除。
  - 常见风险：成套设备分批到货，卖方某关键批次违约，买方仅就该批解除 → 已到货品成为废铁；合同应写明「各批相互依存，任一批根本违约买方可整体解除」。
  - 法律依据：《民法典》第633条。
- [ ] **多交标的物的处理**
  - 审查什么：卖方多交的，买方可接收或拒绝接收多交部分；接收的按合同价格付款，拒绝的应及时通知卖方。
  - 法律依据：《民法典》第629条。
- [ ] **备货与库存风险分配**【高危】
  - 审查什么（买方视角）：定制/贴牌产品取消订单的赔偿计算口径（已投入成本+合理利润 vs 全款）；最小起订量（MOQ）与预测量（forecast）的约束力（滚动预测是否构成承诺）；长交期物料（LTM）备货授权书的效力。
  - 审查什么（卖方视角）：买方框架合同只签意向量不锁量 → 备货后砍单；寄售/VMI（供应商管理库存）模式下货物所有权与灭失风险何时转移、盘点差异承担、滞销品处置与退货条款。
  - 常见风险：框架协议无最低采购量承诺，供应商备料后买方不下单 → 索赔无明确依据（缔约过失/信赖利益举证难）；寄售库存被买方债权人查封。
  - 法律依据：《民法典》第500条（缔约过失责任）、第509条（全面履行与诚信原则）、第577条（违约责任一般条款）；寄售模式参照委托合同/行纪合同规则（第919条、第951条以下）。

### 1.5 结算与票据条款（法律审查部分，财务部分见第二、五部分）

- [ ] **价款与支付时间的明确性**
  - 审查什么：单价、总价、计价货币、大小写一致性；支付时间节点（预付款X%、到货款X%、验收款X%、质保金X%及期限）；未约定支付时间的，买方应在收到标的物或提取单证的同时支付。
  - 法律依据：《民法典》第626条（按约定数额和方式付款）、第628条（按约定时间付款）。
- [ ] **分期付款与加速到期**【高危】
  - 审查什么：分期付款买卖中，买方未支付到期价款达全部价款**1/5**，经催告后合理期限仍未付的，卖方可请求支付全部价款或解除；解除可请求标的物使用费。
  - 常见风险：卖方合同未写入该权利或约定门槛高于法定（法定为最低保护，约定更严条件是否有效有争议）；买方视角警惕「任一期逾期即全部到期」的过苛加速条款。
  - 法律依据：《民法典》第634条。
- [ ] **商业汇票结算的限制（中小企业保护场景）**
  - 审查什么：机关、事业单位、大型企业向中小企业采购，不得强制中小企业接受商业汇票等非现金支付方式，不得利用非现金支付变相延长付款期限；合同付款期限与票据到期日的衔接。
  - 法律依据：《保障中小企业款项支付条例》（国务院令第802号，2025-06-01施行）第11条。第9条规制付款期限，不应作为商业汇票限制的条文依据。

## 第二部分 价格与付款条款审计

### 2.1 定价依据与价格异常信号

- [ ] **定价形成机制留痕**
  - 审查什么：定价依据（招标/比选/询价记录、历史采购价、成本加成测算、政府指导价/市场调节价属性）；价格审批是否经授权层级；价格有效期与调价机制（原材料联动公式、指数挂钩、汇率联动）。
  - 常见风险：无比价记录的单一来源采购且价格高于市场；调价条款单向（只涨不跌）或联动公式参数（基准价、权重、数据来源）不完整。
  - 依据：《价格法》（经营者定价原则、价格欺诈禁止）；内部采购管理制度；《民法典》第511条第2项（价款不明按订立合同时履行地市场价格，依法应执行政府定价/指导价的从其规定）。
- [ ] **价格异常信号（审计红旗）**【舞弊】
  - 明显高于市场公允价：可能存在利益输送、回扣、围标内定；应做三方比价或第三方价格鉴证。
  - 明显低于成本价：警惕以低于成本的价格倾销排挤竞争对手（《价格法》第14条禁止经营者以排挤竞争对手为目的低于成本销售，处理鲜活、季节性、积压商品等除外）；也警惕「低价中标、变更补差」钓鱼式报价。
  - 单价畸高/畸低的清单项目（不平衡报价）：在分批结算中前移利润、后期变更牟利。
  - 整数价、无明细的总价包干且无清单 → 无法做价格分解审计。
- [ ] **政府定价/指导价品种核对**
  - 审查什么：涉及《价格法》第18条政府指导价/政府定价品种（公用事业、公益性服务、自然垄断环节等）的，价格不得突破规定。
  - 依据：《价格法》第18–19条、第39条（不执行政府定价指导价的法律责任）。

### 2.2 付款方式与账期

- [ ] **账期长度与合理性**
  - 审查什么：账期起算点（验收合格/发票开具/收货孰早孰晚——差异巨大）；账期是否与行业惯例、企业现金流匹配；是否存在「背靠背」条款（以下游付款为向上游付款的前提）。
  - 常见风险：「收到业主款后支付」类背靠背条款——2024年最高人民法院批复（法释〔2024〕11号《关于大型企业与中小企业约定以第三方支付款项为付款前提条款效力问题的批复》）：大型企业以第三方支付款项作为向中小企业付款前提的条款**无效**，应按行业规范、交易习惯等确定合理付款期限；普通企业之间该条款效力存争议，审查时标注。
  - 依据：法释〔2024〕11号；《保障中小企业款项支付条例》第9条（付款期限与第三方付款条件规则）。
- [ ] **机关事业单位/大型企业付款期限上限**
  - 审查什么：机关、事业单位从中小企业采购货物、工程、服务，应自交付之日起**30日**内付款；合同另有约定的，付款期限**最长不得超过60日**。大型企业从中小企业采购原则上应自交付之日起**60日**内付款；约定其他期限的，应按行业规范、交易习惯合理约定且不得以收到第三方付款作为付款前提。不得以法定代表人变更、内部流程、等待审计决算等为由迟延付款；不得强制要求以审计结果作为结算依据（无法律行政法规依据时）。
  - 依据：《支付条例》第9条、第15条、第33条。
- [ ] **预付款/进度款比例风险**【高危】
  - 审查什么：预付款比例是否与公司制度/行业惯例匹配（无预付惯例的新供应商高预付＝红旗）；预付款是否有**预付款保函**或等额担保；预付款抵扣安排（从哪一期进度款开始扣回、扣完时点）；进度款计量依据（形象进度/交付批次/里程碑）。
  - 参考基准：建设工程领域预付款惯例为合同金额10%–30%（《建设工程价款结算暂行办法》财建〔2004〕369号）；货物采购无法定比例，>30% 且无担保的应专项说明。
  - 常见风险：全额预付后供应商失联/破产；预付款长期挂账未转成本（资金占用与舞弊信号并存）。
- [ ] **付款条件成就的证据闭环**
  - 审查什么：每笔付款触发条件是否有对应单据支撑（预付款↔合同生效+保函；到货款↔签收单；验收款↔验收报告；质保金↔质保期满证明）；发票是付款条件还是付款后义务（见第三部分）。
  - 常见风险：以「付款申请单+发票」付款而无验收证据 → 付了款但货未验收合格，丧失质量抗辩空间。
- [ ] **逾期付款利息/违约金**【高危】
  - 审查什么：是否约定逾期付款违约金或计算方法及标准（日万分之X）；未约定时买方的法定风险与卖方的法定救济。
  - 规则：
    - 有约定从约定（过高可调：《民法典》第585条第2款，违约金过分高于损失的，法院/仲裁机构可适当减少——司法实践一般以超过损失30%为「过分高于」参考）；
    - 无约定的，出卖人可主张逾期付款损失：违约行为发生在2019-08-20之后的，法院可以违约行为发生时**一年期LPR为基础加计30%–50%**计算（《买卖合同解释》第18条第4款；用词为「可以」，法院有自由裁量权）；
    - **中小企业卖方特别保护**：机关、事业单位、大型企业迟延支付中小企业款项的，有约定从约定但**约定利率不得低于合同订立时1年期LPR**；未约定的按**日利率万分之五**（年化约18.25%）支付逾期利息（《支付条例》第17条）——该标准优先于一般LPR规则。
  - 常见风险：作为买方的大企业合同写「逾期付款按银行同期存款利率计息」→ 对中小企业供应商该约定无效（不得低于1年期LPR）；卖方未约定违约金 → 只能按LPR加计主张，举证与裁量不确定性大。
- [ ] **票据结算风险**
  - 审查什么：商业承兑汇票 vs 银行承兑汇票的信用差异；票据期限与账期叠加（6个月商票实质拉长账期）；出票人信用核查；背书转让与贴现费用承担；电子票据系统操作与提示付款期限；票据拒付时回归基础合同债权的选择（原因债权与票据债权的关系）。
  - 常见风险：收取资信差的商票到期拒付；合同只写「以承兑汇票支付」未写明银行/商业、期限、贴息承担 → 变相降价。
  - 依据：《票据法》（追索权规则）；《支付条例》（不得强制中小企业接受非现金支付、不得借票据变相延长付款期限）。
- [ ] **结算币种与汇率（涉外）**
  - 审查什么：计价币种、结汇时点、汇率波动承担、跨境支付的合规路径（外汇管理）。
  - 依据：《外汇管理条例》。

### 2.3 款项抵销、扣款与质量扣款条款

- [ ] **买方扣款权边界**
  - 审查什么：质量扣款、违约金扣减是否约定通知与确认程序；卖方是否接受「买方单方认定即可扣款」条款；扣款争议的先行支付无争议部分义务。
  - 依据：《民法典》第568–569条（抵销）；《支付条例》第15条（部分有争议不影响无争议部分及时付款）。
- [ ] **质保金扣留比例与返还**
  - 审查什么：质保金比例（常见3%–10%）、扣留基数（合同额/每批货款）、返还时点与程序（质保期满+无质量问题确认+X日内无息返还）；质保金是否接受保函替代（《支付条例》场景下不得强制现金保证金，应接受保函）。
  - 常见风险：质保期满返还条件含糊（「经买方确认无质量问题后支付」无时限）→ 变相无限期扣款；质保金不约利息长期挂账。

## 第三部分 税务与发票审查

### 3.1 税率与价格表述

- [ ] **税目与税率核对**【税务】
  - 审查什么：合同标的适用的增值税税率是否与交易实质一致：销售货物、加工修理修配、有形动产租赁 **13%**；交通运输、邮政、基础电信、建筑、不动产租赁、销售不动产、转让土地使用权及列举货物（农产品等）**9%**；现代服务等其他服务、无形资产 **6%**；出口货物零税率；小规模纳税人适用征收率（3%档，减按政策另查当期有效文件）。
  - 常见风险：混合销售/兼营未拆分（货物+安装、设备+服务混在13%总价中——分别核算适用不同税率的从高或分别适用，约定不清引发税负争议与开票错误）；供应商为小规模纳税人却承诺开13%专票（只能开3%/1%征收率发票，进项抵扣差额损失）。
  - 依据：《增值税法》第10条（税率）、第12条（混合销售/兼营规则，以现行文本为准）；《增值税法实施条例》。
- [ ] **含税价 vs 不含税价表述**【高危】【税务】
  - 审查什么：合同金额是否写明「含税价/不含税价」、税额单列（价税分离：不含税金额 X 元，税额 X 元，价税合计 X 元）；大小写一致。
  - 常见风险：只写总价未写含税与否 → 税率调整后双方争夺税额差额；以「不含税价成交、不开票」做交易 → 偷逃税风险，买方无法取得抵扣凭证且付款无合规列支凭证；个人供应商约定「税费由买方承担」未量化。
  - 依据：《增值税法》第7条（增值税为价外税，应税交易的销售额不包括增值税税额）；《发票管理办法》（应开未开发票的处罚）。
- [ ] **税率调整条款**
  - 审查什么：约定「如遇国家税率政策调整，不含税价不变、税额相应调整」或相反；跨税率调整期间履行的合同（签约时13%、开票时新税率）按纳税义务发生时间适用税率。
  - 常见风险：固定含税总价 + 税率下调 → 卖方获得税率红利；税率上调则卖方抗辩要求涨价。应明确政策调整的利益归属。
  - 依据：《增值税法》第28条（纳税义务发生时间）；历史参照：财政部 税务总局 海关总署公告2019年第39号（16%→13%、10%→9%调整实践）。

### 3.2 发票类型与开具要点

- [ ] **专票 vs 普票约定**【税务】
  - 审查什么：明确约定开具「增值税专用发票」（买方为一般纳税人且用于可抵扣用途时）还是普通发票；开票信息（购买方名称、税号）与合同主体一致；数电票（全面数字化的电子发票）交付方式。
  - 常见风险：卖方只能开普票（小规模/简易计税）→ 买方进项损失应在价格中体现；约定专票但税率栏与合同不符；「替票」「大头小尾」属虚开红线。
  - 依据：《发票管理办法》（国务院令修正，2023年修订）；《增值税专用发票使用规定》（国税发〔2006〕156号，开具时限按纳税义务发生时间）。
- [ ] **发票开具时点与付款先后关系**【高危】【税务】
  - 审查什么：「先票后款」还是「先款后票」：买方常要求「收到合规发票后X日内付款」（以票控款），卖方现金流受损；卖方要求先款后票则买方承担付款后拿不到票的税务与报销风险。
  - 税务规则：**先开具发票的，增值税纳税义务于开票当日发生**——即「先开票先纳税」，卖方提前开票即提前缴税，可能货未收款先垫税；买方取得专票即可按规定抵扣（不以付款为前提）。
  - 风险设计建议：折中安排——「卖方于每笔付款前开具等额发票」+ 迟延开票违约金；或先款后票时约定迟延开票的滞纳赔偿与 withholding 权。
  - 依据：《增值税法》第28条第1款（发生应税交易，纳税义务发生时间为收讫销售款项或取得销售款项索取凭据的当日；**先开具发票的，为开具发票的当日**）。
- [ ] **发票与合同、付款的匹配（三流一致）**【高危】【税务】
  - 审查什么：**合同流（签约主体）、资金流（收付款账户）、发票流（开票方/受票方）三流一致**（货物流/服务流一致）。核查：开票方=合同卖方=收款账户户名；受票方=合同买方=付款账户户名。
  - 常见风险：第三方代付款/代收款（母公司代付、员工个人账户收付）→ 进项抵扣被质疑、被认定虚开风险；委托收付款应有书面三方协议或委托付款函留痕。
  - 依据：国家税务总局关于加强增值税征收管理的文件确立的「三流一致」抵扣管理要求（国税发〔1995〕192号，实务沿用其口径；引用时建议核对现行有效口径）；《发票管理办法》第21条（虚开发票的界定：开具与实际经营业务情况不符的发票等）。
- [ ] **虚开发票红线**【舞弊】【税务】
  - 审查什么：无真实交易或交易金额、品名不实的发票；「变票」（变更品名规避消费税/抵扣限制）；让他人为自己开具与实际不符发票。刑事风险：虚开增值税专用发票罪（《刑法》第205条）。
  - 审计动作：比对合同标的、出入库记录、物流单据与发票品名、数量、金额的一致性。

### 3.3 其他税务要点

- [ ] **印花税**
  - 审查什么：买卖合同属印花税应税凭证，税率**价款的万分之三**（不含列明增值税）；双方均为纳税人；电子订单/要货单是否构成应税凭证；境外签订的应税凭证境内使用时申报义务。
  - 依据：《印花税法》（2022-07-01 施行）附件《印花税税目税率表》。
- [ ] **税费承担条款**
  - 审查什么：「一切税费由X方承担」类包税条款的范围（是否含增值税、附加、所得税——包税条款不转移法定纳税义务人身份，仅在双方间分摊负担）；向个人采购/支付的代扣代缴义务（个税、增值税代征情形）。
  - 风险提示：包税条款因约定不明引发的诉讼高发；税后价折算公式应写明。
- [ ] **出口退税相关（涉外销售）**
  - 审查什么：贸易方式（一般贸易/加工贸易）、退税主体、报关单与发票一致性、跨境应税行为退（免）税资格。
  - 依据：《增值税法》第10条（出口货物零税率）及出口退税管理文件。
- [ ] **供应商纳税人身份核查**
  - 审查动作：通过「全国增值税发票查验平台」、企业信用信息公示系统核查对方一般纳税人资格、税收违法「黑名单」、经营异常名录；小规模纳税人供应商的价格应折算不可抵扣税额后比价。

## 第四部分 审计视角的采购销售舞弊信号（红旗清单）

> 使用方式：以下为**信号（红旗）**而非定论。命中信号 → 升级核查（函证、访谈、穿透资金流/物流、工商穿透、实地盘点），不得仅凭信号定性。

### 4.1 价格类信号

- [ ] 采购价显著高于同期市场价/历史价/内部其他渠道价，且无规格、服务差异解释。
- [ ] 销售价显著低于成本或市场价，且客户为关联方或新设主体（利益输出、转移利润）。
- [ ] 长期固定价格不随市场波动调整（大宗商品尤甚）——可能锁定利益输送通道。
- [ ] 价格波动条款被选择性启用（只调涨不调跌、调价审批缺失）。
- [ ] 高价采购后立即低价转售（高买低卖），货物流向与资金流背离。

### 4.2 虚假贸易背景信号（融资性贸易 / 空转走单 / 循环贸易）

> 监管口径：652号文定义融资性贸易＝**以贸易为名实为出借资金、无商业实质**的违规业务；「空转」「走单」＝缺乏实物流或现金流、完全脱离贸易实质的虚假贸易。74号文「十不准」禁止央企：背离主业贸易、特定利益关系企业间无商业目的贸易、人为增加不必要交易环节、任何形式融资性贸易、无控制权的空转走单、无商业实质循环贸易、有悖交易常识的异常贸易、高风险非标仓单交易、违反会计准则确认代理贸易收入、内控缺失下开展贸易。国企合同审计应逐条对照。

- [ ] **融资性贸易特征**：上下游为同一实际控制人或特定利益关系；标的由交易对方实际控制（卖方仓库直发买方指定下游，企业无控制权）；固定收益、不承担价格波动与存货风险（差价=资金利息）；账期与资金占用量匹配利息逻辑；票据、保理、增信安排嵌套。
- [ ] **空转/走单特征**：货物存放第三方仓库不动，仅凭货权转让凭证/仓单背书完成「交易」；无物流单据或物流单据造假（车牌、运单号查无记录）；闭环走单（A→B→C→A）仅做大流水。
- [ ] **循环贸易特征**：同一批货物在短时间内多次转手回到起点或关联方；合同链条环环相扣、背靠背条款严密但无终端真实需求方；毛利率异常稳定且趋近于零或为「通道费」水平。
- [ ] 仓单类：非标仓单、无法核验仓储方独立性、仓单重复质押。
- [ ] 会计信号：代理业务按总额法确认收入（应为净额法）做大营收；期末突击确认贸易收入、期后大量退回或红冲。

### 4.3 供应商/客户关联关系信号

- [ ] 供应商/客户与本公司员工、高管存在股权、亲属、代持关系（工商穿透：股东、法定代表人、注册地址、联系电话、邮箱雷同）。
- [ ] 供应商注册时间短、注册资本小、参保人数少/为零、注册地址为住宅或集群注册，却承接大额订单。
- [ ] 中标供应商与其他投标人的报价、文件、保证金缴纳账户雷同（见4.4）。
- [ ] 供应商收款账户频繁变更、收款人为个人或第三方公司。
- [ ] 客户/供应商为「壳」特征：无官网、无经营痕迹、税务零申报、与交易规模不匹配的社保人数。

### 4.4 围标串标与规避招标信号

- [ ] **围标串标迹象**：多家投标文件格式、错漏、排版雷同；报价呈规律性差异（陪标价梯度）；不同投标人保证金从同一账户转出或同一经办人办理；中标价贴近标底/最高限价；中标人随即转包/分包给「陪标人」；评标前信息泄露（意向中标人提前备货）。
  - 法律依据：《招标投标法》第32条（禁止投标人相互串通、与招标人串通）；《招标投标法实施条例》第39–41条（串通投标、视为串通投标的情形）；《刑法》第223条（串通投标罪，情节严重处三年以下有期徒刑或拘役，并处或单处罚金）。
- [ ] **化整为零规避招标**：将依法必须招标项目拆分为多个低于限额的小合同（时间集中、品目相同、供应商相同或关联）；先小额签约再大额补充协议/变更使实际金额超限；以「框架协议+订单」形式规避。
  - 法律依据：《招标投标法》第4条（不得化整为零或以其他任何方式规避招标）；《招标投标法实施条例》第24条（不得利用划分标段规避招标）；必须招标范围见《必须招标的工程项目规定》（发改委令第16号）及第843号令《必须招标的基础设施和公用事业项目范围规定》。
  - 审计动作：按「同一时期+同一品目+同一供应商」聚合合同金额，与招标限额比对。
- [ ] **单一来源/紧急采购滥用**：紧急采购事由不充分且反复发生；单一来源论证流于形式；竞争对手被排他性技术参数（指向特定品牌型号）排除。

### 4.5 履约与资金类信号

- [ ] 预付款长期挂账（超过合同约定交付期未转销）——挪用或虚假交易。
- [ ] 同一供应商大额整数付款、无明细结算单。
- [ ] 付款节奏异常：未到付款节点提前付款、拆分付款规避审批权限。
- [ ] 验收流于形式：验收单集中补签、验收人非授权人员、无质检记录却签「合格」。
- [ ] 退货/红冲集中在期末（收入调节）；质保金异常豁免或提前退还。

## 第五部分 财务一致性核对要点

### 5.1 合同金额与预算/入账的一致性

- [ ] **合同台账—预算—账面三方核对**
  - 合同总金额（含补充协议、变更）vs 立项/预算批复金额：超预算合同是否有追加审批；预算外采购的审批缺失即内控缺陷。
  - 合同累计付款 vs 合同约定付款节点：超前付款、超额付款（含未扣回的预付款、未扣质保金）逐项列示。
  - 账面入账金额 vs 合同金额：暂估入账与发票到达差异；长期「暂估应付」挂账未核销。
  - 合同金额与发票累计金额、付款累计金额三方勾稽（不含税口径对账时注意价税分离）。
- [ ] **收入/采购确认时点与合同条款匹配**
  - 核对收入确认时点（控制权转移）与合同约定的交付、验收条款是否一致：以验收为付款前提的合同，提前确认收入的风险；总额法/净额法判断（代理人 vs 主要责任人，《企业会计准则第14号——收入》）。
  - 跨期检查：年末大额销售/采购合同的发货、签收、验收、开票、回款时间分布，识别提前或延后确认（cut-off）。
- [ ] **合同资产/应收与合同负债核对**
  - 已履约未收款（应收/合同资产）与合同收款权时点核对；预收/合同负债与未履行交付义务匹配；长账龄应收对应合同是否已超异议期/诉讼时效（3年，《民法典》第188条；国际货物买卖和技术进出口合同4年，第594条）。

### 5.2 履约保证金/质保金的会计处理关注点

- [ ] **履约保证金**
  - 会计核对：支付方挂「其他应收款」、收取方挂「其他应付款」，**不得**计入成本费用或直接冲收入；保证金的收付与合同约定节点核对（签约后X日内支付、竣工验收/质保期满后X日内退还）。
  - 比例基准：招投标场景履约保证金不得超过中标合同金额的**10%**（《招标投标法实施条例》第58条）；投标保证金不得超过招标项目估算价的**2%**（第26条）；政府采购履约保证金不得超过合同金额的10%（《政府采购法实施条例》第48条）。超比例收取＝违规信号。
  - 形式：现金 vs 保函/保险；现金保证金是否被挪用（账实核对、银行询证）；退还是否及时、有无逾期占用（机关事业单位/大型企业拖欠退还保证金亦属《支付条例》清理范围）。
- [ ] **质保金（质量保证金）**
  - 扣留方（买方）核对：扣留比例与基数符合合同；「其他应付款—质保金」台账按合同/项目分明细；到期返还审批与质保期内维修索赔冲抵的书面依据。
  - 被扣方（卖方）核对：质保金挂账回收性评估（质保期满未收回应查明原因）；保证类质保的预计负债计提（产品质量保证义务，《企业会计准则第13号——或有事项》/收入准则应用指南：保证类质保按或有事项处理，服务类质保作为单项履约义务分摊交易价格——《企业会计准则第14号——收入》第33条）。
  - 舞弊信号：质保金被「违约金」「罚款」名义长期克扣无依据；质保期内维修费用未从质保金列支而重复入账。
- [ ] **保证金利息归属**
  - 审查什么：大额保证金占用期间利息归属是否约定；无息占用是否构成变相商业贿赂或利益输送的评估。

### 5.3 对账与函证衔接

- [ ] 定期对账制度执行：合同约定对账周期（月度/季度）与实际对账单签署情况；对账单签章效力（公章/财务章/经办人签字的授权）。
- [ ] 审计函证金额与合同台账差异分析；未回函项目的替代程序（检查发货、签收、发票、回款）。
- [ ] 诉讼时效管理：对账中断时效（《民法典》第195条：权利人提出履行请求时效中断重新计算）；临近3年时效的应收合同清单。
