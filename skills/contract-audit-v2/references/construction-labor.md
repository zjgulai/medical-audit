# 建设工程合同专项 + 劳动/人事相关协议专项审查要点

> **定位**：contract-audit skill 专项参考。建工类合同加载第一部分，劳动/人事协议加载第二部分（可按需只读对应部分）。
> 用途：逐条对照检查，命中即提示风险并给出依据。
> 标记约定：【效力】影响合同/条款效力；【高危】实务高发争议；【程序】程序性瑕疵；【提示】优化建议。
> 主要依据简称：《建工解释一》＝最高人民法院《关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）》（法释〔2020〕25号）；《劳争解释一》＝《关于审理劳动争议案件适用法律问题的解释（一）》（法释〔2020〕26号）；《劳争解释二》＝《关于审理劳动争议案件适用法律问题的解释（二）》（法释〔2025〕12号，2025-09-01 施行）；《16号令》＝《必须招标的工程项目规定》（国家发改委令第16号，2018-06-01 施行）。

# 第一部分 建设工程合同专项审查清单

## 1. 主体资质与合同效力

- [ ] **承包人资质核验**
  - 核验营业执照、建筑业企业资质证书（施工总承包/专业承包/施工劳务序列及等级）、安全生产许可证（有效期内）。依据：《建筑法》第13条（按资质等级承揽工程）、《安全生产许可证条例》（建筑施工企业未取得安全生产许可证不得从事生产活动）。
  - 【效力】承包人无资质或超越资质等级订立施工合同 → 合同无效（《建工解释一》第1条第1项）。
  - 【效力】合同约定的承包范围与承包人资质等级/专业类别不匹配（越级承揽），无效风险；《建筑法》第26条禁止越级承揽。
  - 【提示】合同无效但工程竣工验收合格的，承包人可请求"参照合同关于工程价款的约定折价补偿"（《民法典》第793条）——无效不等于免费，审查时提示当事人别以为无效就能赖账。
- [ ] **挂靠/借用资质排查**【高危】
  - 红旗信号：签约主体与实际组织施工、收款主体不一致；项目部人员社保不在承包人处；管理费/挂靠费条款（如"上交X%管理费"）；承包人仅出借公章账户。
  - 【效力】没有资质的实际施工人借用有资质企业名义签订的施工合同无效（《建工解释一》第1条第2项）。
  - 发包人与挂靠人/被挂靠人对因出借资质造成的损失承担连带赔偿责任（《建筑法》第66条）。
  - 新版《建工解释（二）》（2026年发布）进一步明确：出借资质合同无效，资质借用费/使用费不受保护；工程质量合格的，借用方可请求参照约定折价补偿。
- [ ] **转包、违法分包条款**
  - 禁止转包（承包人将其承包的全部工程转给他人/肢解后以分包名义转包）、《建筑法》第28条、《民法典》第791条。
  - 违法分包情形：分包给无资质单位；未经发包人认可的分包（总包合同约定或建设单位认可除外）；主体结构施工分包；分包单位再分包。
  - 【高危】合同中"发包人同意一切分包"或空白授权条款——提示限制为"经发包人书面认可且分包人具备相应资质"。
- [ ] **发包人手续**
  - 核验：建设用地规划许可、建设工程规划许可、施工许可证（未取得施工许可擅自施工属违法，且《建工解释一》第3条：发包人未取得建设工程规划审批手续的合同无效，起诉前取得的除外——表述以现行解释为准核对）。
  - 【提示】政府投资项目需立项/概算批复；资金来源落实情况（垫资风险预判）。

## 2. 招标投标合规与"黑白合同"

- [ ] **是否属于必须招标项目**（先判断，再审查程序）
  - 范围（《招标投标法》第3条 + 《16号令》第2-4条）：
    ① 全部/部分使用国有资金或国家融资：使用预算资金200万元以上且占投资额10%以上；或国企事业单位资金占控股/主导地位；
    ② 使用国际组织/外国政府贷款援助资金；
    ③ 大型基础设施、公用事业等关系公共利益公众安全项目（能源、交通、通信、水利、城轨等，按发改委规定目录）。
  - 规模标准（《16号令》第5条）：施工单项合同估算价 ≥ 400万元；重要设备材料货物 ≥ 200万元；勘察设计监理等服务 ≥ 100万元。同一项目中可合并采购的合计达到标准的，必须招标（防止化整为零规避招标）。
  - EPC 总承包：施工/货物/服务任一部分达到上述标准即须招标（发改办法规〔2020〕770号答复口径）。
  - 【效力】必须招标而未招标或中标无效的 → 施工合同无效（《建工解释一》第1条第3项）。
- [ ] **黑白合同/阴阳合同规则**【高危】
  - 规则一：招标人与中标人另行订立的合同，其工程范围、工期、质量、价款等实质性内容与中标合同不一致的，一方请求按中标合同确定权利义务的，法院支持（《建工解释一》第2条；《招标投标法》第46条禁止订立背离实质性内容的其他协议）。
  - 规则二：签订的中标合同与招标文件、投标文件、中标通知书载明的范围、工期、质量、价款不一致的，可请求以招投标文件作为结算工程价款依据（《建工解释一》第22条）。
  - 规则三：中标人另行作出明显高于市场价购买房产、无偿建设配套设施、让利、捐款等承诺 → 认定为变相降低工程价款、背离实质性内容（《建工解释一》第2条第2款口径）。
  - 不属于"黑合同"的安全区：履行中因客观情况变化（工程量增减、设计变更、停窝工损失安排、付款节点调整）签订补充协议，未排除其他竞标人中标条件、未致权利义务严重失衡的，一般认可其效力（最高法裁判口径）。
  - 【审查动作】要求当事人提供招投标全套文件比对；发现同一工程存在两份及以上合同/补充协议时，标注"黑白合同"风险并比对价款、工期、质量、范围四要素。
  - 新动向：《建工解释（二）》（2026年发布）进一步规定"确定中标人前即就实质性内容谈判且该投标人中标"（串标）、"先签合同后走招标程序"（明招暗定）两种情形应认定中标合同无效。
- [ ] **招标程序瑕疵**【程序】
  - 检查：中标通知书、30日内订立书面合同（《招标投标法》第46条）；投标保证金比例（≤项目估算价2%，《招标投标法实施条例》第26条）；串通投标、以他人名义投标等导致中标无效的情形（《招标投标法》第32/33条）。

## 3. 合同价款形式与结算机制

- [ ] **价款形式识别与风险提示**
  - 固定总价：承包人承担量与价的双重风险。审查点：①是否有明确的风险范围与调整条件（材料价格异常波动、政策性调整、设计变更、不可抗力）；②包干范围边界是否清晰（图纸范围、清单范围）；③无调价条款时对承包人高危、对发包人有利但注意《建工解释二》（2026）已明确工期内人工费、主要建材价格重大变化原则上不构成固定价调整事由（另有约定或构成情势变更除外）。
  - 固定单价：按实计量，量风险在发包人、价风险在承包人。审查点：单价包含内容（人材机管理利润税金）、计量规则、清单缺漏项/特征不符的调价机制。
  - 可调价格：明确调整因素（造价信息价、政策文件、人工费调整文件）、调整方法与周期、不调整的兜底表述风险。
  - 成本加酬金：明确成本范围、酬金计取方式（固定额/百分比）、审计确认程序；对发包人高危（成本失控）。
- [ ] **工程量清单**【高危】
  - 清单是否作为合同组成部分；工程量偏差超约定幅度（常见±15%）时的综合单价调整机制；清单漏项、项目特征描述不符的处理规则（参照《建设工程工程量清单计价规范》GB50500 的通行做法：由发包人承担清单准确性责任）。
- [ ] **暂列金额、暂估价、计日工**
  - 暂列金额归属（归发包人掌握使用，剩余归发包人）是否写明；专业工程/材料暂估价达到招标标准的是否约定依法招标；计日工单价表是否完整。
- [ ] **变更与签证**【高危】
  - 是否有：变更指令的书面形式要求（发包人/监理书面指令）；签证时限（事件发生后天数内提交，逾期后果表述）；签证权限人（总监/发包人代表）及越权签证的效力约定。
  - 司法规则：《建工解释一》第19条——工程量争议按施工过程中形成的签证等书面文件确认；承包人未能提供签证但能证明发包人同意施工的，可按其他证据确认实际工程量（即"没有签证≠必然败诉"，但举证负担重）。
  - 【高危红旗】"未按约定期限办理签证视为放弃一切费用/工期索赔"——对承包人极端不利条款，提示谈判弱化（改为"视为放弃该次索赔程序权利但保留举证权"或延长期限）。
- [ ] **索赔程序**
  - 索赔事件通知时限（示范文本通常28天）、同期记录要求、索赔报告内容；工期索赔与费用索赔分开约定；发包人反索赔机制对等性。
- [ ] **结算条款**【高危】
  - 结算依据、结算期限（承包人提交竣工结算文件→发包人审核期限）、逾期审核后果。
  - 关键规则：《建工解释一》第21条口径——约定"发包人收到竣工结算文件后在约定期限内不予答复视为认可"的，从约定（"逾期视为认可"条款必须明确约定才适用，仅援引示范文本通用条款可能不被支持，审查时要求在专用条款中写明）。
  - 政府投资项目"以审计结论作为结算依据"条款：属约定则按约定，但审计久拖不决的承包人有救济；《建工解释二》（2026）明确审计逾期不出具或明显不符可申请司法鉴定，未约定合理期限的法院确定期限最长不超过一年。
  - 固定价结算排除造价鉴定：约定按固定价结算的，一方请求对工程造价鉴定的，不予支持（《建工解释一》第28条）。

## 4. 工期、质量、验收、缺陷责任与质保金

- [ ] **工期条款**
  - 开工日期认定（《建工解释一》第8条）：一般以开工通知载明日期为准；通知发出后尚不具备开工条件的以具备条件之日；承包人原因推迟的以通知载明日期；经同意已实际进场施工的以实际进场之日。
  - 竣工日期争议（《建工解释一》第9条）：①验收合格的以验收合格之日；②承包人已提交验收报告发包人拖延验收的，以提交验收报告之日；③未经验收发包人擅自使用的，以转移占有之日。
  - 审查点：开竣工日期是否具体（避免"以实际开工为准"悬空）；总日历天数与日期双重校验；节点工期（里程碑）与总工期关系。
- [ ] **工期顺延**【高危】
  - 顺延事由是否完整：不可抗力、异常恶劣天气、发包人未按期提供图纸/场地/资金、设计变更、工程量增加、政府行为、第三方原因。
  - 顺延程序：承包人是否在约定期限内提出并办理签证——《建工解释一》第10条：约定顺延工期应经签证等方式确认，承包人未在约定期限内申请但主张顺延的，法院审查其未申请是否有正当理由及是否在诉讼前提出过；约定"未按期申请视为不顺延"的按约定（除承包人在约定期限后申请且发包人同意，或有证据证明发包人知道且未反对等例外）。审查时提示承包人：程序条款具有实体后果。
- [ ] **逾期竣工违约金**
  - 比例是否畸高（常见每日万分之三至万分之五或日固定额）；是否设上限（常见为合同价款的3%-5%）；与发包人逾期付款违约金是否对等（单边重罚条款提示显失公平风险，《民法典》第585条违约金酌减规则兜底）。
- [ ] **质量标准与验收**
  - 质量标准表述：合格/优良/奖项（创优工程注意：约定"必须获得XX奖否则扣款"的，未获奖原因复杂，高危争议条款；建议改为"达到参评标准并配合申报"）。
  - 验收程序：中间验收、隐蔽工程验收（通知时限+逾期视为认可并剥离检查费用承担）、竣工验收组织主体、竣工验收备案。
  - 发包人擅自使用未验收工程的后果：以转移占有日为竣工日，且发包人对使用部分质量问题自担（地基基础和主体结构除外）（《建工解释一》第14条口径）。
- [ ] **缺陷责任期与质量保修**（两个概念必须区分）
  - 缺陷责任期（钱）：一般为1年，最长不超过2年，由双方约定（《建设工程质量保证金管理办法》第2条）；自工程通过竣工验收之日起计；承包人原因拖延验收的自实际通过之日计；发包人原因的，承包人提交竣工验收报告90天后自动进入。
  - 保修期（活）：法定最低保修期限——地基基础和主体结构为设计文件规定的合理使用年限；屋面防水、有防水要求的卫生间/外墙面防渗漏5年；供热供冷2个采暖/供冷期；电气管线、给排水管道、设备安装和装修2年（《建设工程质量管理条例》第40条）。约定低于法定最低期限的无效。
  - 【高危红旗】将质保金返还与"保修期满"（如防水5年）挂钩 → 变相超期扣留质保金，违反缺陷责任期最长2年的规定，提示删除或改为2年。
- [ ] **质保金条款**【高危】
  - 比例红线：保证金总预留比例不得高于工程价款结算总额的3%（《建设工程质量保证金管理办法》第7条）；以银行保函替代的保函金额同样≤3%。
  - 已缴纳履约保证金的，竣工前不得同时预留质保金（办法第6条）。
  - 返还：缺陷责任期届满承包人申请返还，发包人应在约定期限内核实返还；逾期返还的违约金条款建议补齐。
  - 审查点：每期进度款扣留比例与累计上限；返还节点（建议缺陷责任期满+结算后X日）；缺陷维修程序（通知→承包人维修→拒不维修时发包人可委托第三方并从保证金扣款，须约定费用确认机制）。

## 5. 工程款支付、垫资、实际施工人、优先受偿权

- [ ] **支付链条完整性**
  - 预付款：比例（常见10%-30%）、支付时间、扣回方式（起扣点公式）、预付款保函。
  - 进度款：计量周期、支付比例（常见70%-85%）、审核支付时限、逾期支付利息（LPR/约定利率）。
  - 结算款：竣工验收/结算完成后支付至结算价的97%（质保金3%外）时限。
  - 农民工工资专用账户与总包代发制度（《保障农民工工资支付条例》）：政府投资项目不得由施工单位垫资建设（该条例第22条口径）。
- [ ] **垫资条款效力**
  - 规则（《建工解释一》第25条）：①对垫资及利息有约定的，按约定，但约定利息高于垫资时同类贷款利率/同期LPR的部分除外；②对垫资没有约定的，按工程欠款处理；③对垫资利息没有约定的，不支持利息。
  - 【高危红旗】名为"垫资"实为变相融资、或垫资+高息组合——审查利息是否超过LPR；政府投资项目垫资条款违规风险单独提示。
  - 注意与"工程欠款"利息规则区分：欠付工程价款利息有约定从约定，无约定按同期同类贷款利率/LPR（《建工解释一》第26/27条口径），利息自应付工程价款之日计付。
- [ ] **实际施工人权利**（对发包人的穿透风险）
  - 规则（《建工解释一》第43条）：实际施工人可以转包人、违法分包人为被告起诉；以发包人为被告主张权利的，法院追加转包人/违法分包人为第三人，发包人在欠付工程价款范围内对实际施工人承担责任。
  - 【提示】发包人侧审查：合同应要求承包人不得转包违法分包+承诺对外债务自担+发包人有权直接从应付工程款中代付农民工工资/材料款并抵扣。
  - 新动向：《建工解释二》（2026）收窄实际施工人直接起诉发包人路径，转包/违法分包情形下接受转包、违法分包的单位个人原则上不得再直接请求无合同关系的发包人支付——提示以合同相对方请求、代位权诉讼为主。审查存量合同与争议预案时注意新旧衔接。
- [ ] **建设工程价款优先受偿权**（《民法典》第807条）
  - 核心规则（《建工解释一》第35-42条）：
    ① 主体：与发包人订立施工合同的承包人（装饰装修工程承包人亦享有，以该工程为限，第37条）；
    ② 前提：建设工程质量合格（含未竣工但已完部分质量合格，第38/39条）；
    ③ 顺位：优于抵押权和其他债权（第36条）；商品房消费者权利优先问题按相关批复另行判断；
    ④ 范围：依国务院有关主管部门规定范围确定，逾期利息、违约金、损害赔偿金不属优先范围（第40条）；
    ⑤ 期限：最长不超过18个月，自发包人应当给付工程价款之日起算（第41条）；
    ⑥ 放弃限制：发包人与承包人约定放弃或限制优先权损害建筑工人利益的，该约定无效（第42条）。
  - 【高危红旗】发包人（或其贷款银行）要求承包人出具"放弃优先受偿权承诺函"——审查是否损害建筑工人利益；提示承包人放弃条款可能被认定无效但亦增诉讼成本。
  - 【提示】付款节点条款直接决定18个月起算点；结算协议中重新约定给付日期的，优先权期限可自变更后的应付日起算（《建工解释二》第21条）。

## 6. 建工合同其他高发条款

- [ ] 履约保证金：比例是否超中标合同金额10%（《招标投标法实施条例》第58条上限）；退还节点；与质保金不得重复扣留。
- [ ] 保险：建筑工程一切险/安装工程一切险投保主体、第三者责任险、工伤/意外伤害险；免赔与理赔配合条款。
- [ ] 安全文明施工费：不可竞争费用性质，不得作为让利内容；支付方式（开工后X日内预付不低于50%的通行规定，按地方文件核对）。
- [ ] 材料设备供应：甲供材的范围、损耗率、保管费、价差处理；甲指乙供的品牌限定与替换程序。
- [ ] 税费：税率调整时合同价款是否含税联动（"营改增"类条款）；发票开具与付款先后关系（"先票后款"对承包人高危——发包人可能以未开票拒付，建议约定"付款与开票对应、不得以未开票拒绝支付到期款项"或限缩）。
- [ ] 争议解决：诉讼（工程所在地/施工行为地为合同履行地，《建工解释一》专属管辖口径——建设工程施工合同纠纷按不动产纠纷确定管辖，《民诉法解释》第28条）vs 仲裁（明确仲裁机构全称）；"或裁或诉"条款无效风险。
- [ ] 送达与通知、代表人权限（项目经理/总监签字权限界定，越权签证效力）、合同文件组成与解释顺序（协议书→中标通知书→投标函→专用条款→通用条款→技术标准→图纸→清单，前后矛盾时的顺序约定）。

# 第二部分 劳动/人事相关协议专项审查清单

> 适用范围：劳动合同、聘用合同、试用期协议、培训服务期协议、竞业限制协议、保密协议、劳务外包协议、劳务派遣协议、实习/退休返聘协议、协商解除协议等。

## 1. 协议定性与主体识别（先定性，再审条款）

- [ ] **劳动关系 vs 劳务/承揽/合作关系**
  - 实质判断要素（人身从属性+经济从属性+组织从属性）：接受考勤/规章制度管理、按月固定发薪、提供劳动工具场所、工作内容属单位业务组成部分 → 倾向认定劳动关系。
  - 【高危红旗】名为"劳务协议/合作协议/兼职协议"但具备上述要素 → 按劳动关系处理，单位面临补缴社保、二倍工资、经济补偿风险。标题不决定性质。
  - 特殊主体：在校实习（勤工助学不视为就业）、退休返聘（已享受养老保险待遇按劳务关系，《劳争解释一》第32条口径；注意《劳争解释二》已废止该款并重构规则，审查时按最新解释核对）、非全日制（日均≤4小时、周累计≤24小时、不得约定试用期、可口头、随时终止无补偿，劳动合同法第68-72条）。
- [ ] **签约主体与用工主体一致性**
  - 用人单位须具备用工主体资格（营业执照/登记证书）；筹备期、分支机构签约的授权问题。
  - 关联公司混同用工：《劳争解释二》规则——已订立书面劳动合同的按合同确认劳动关系；均未订立的按用工管理行为，综合工作时间、内容、报酬支付、社保缴纳等因素认定；关联单位可能承担连带责任。
  - 建筑领域转包分包给不具备合法经营资格的组织/个人的，承包人、被挂靠人承担用工主体责任（支付劳动报酬、工伤保险待遇，《劳争解释二》+原劳社部文件口径）。
- [ ] **书面合同订立时限**
  - 用工之日起1个月内订立书面劳动合同；超过1个月不满1年未订立的，每月支付二倍工资（劳动合同法第82条）；满1年未订立视为已订立无固定期限合同（第14条）。
  - 【高危红旗】"先试用后签合同""入职满一年再签"——直接触发二倍工资。
  - 电子劳动合同：符合《电子签名法》可靠的电子签名且可调取查用的，合法有效（人社部电子劳动合同指引口径）。

## 2. 劳动合同必备条款与试用期

- [ ] **必备条款逐项核对**（劳动合同法第17条，缺项不是合同无效但触发责令改正/赔偿责任，第81条）
  - ①用人单位名称、住所和法定代表人/主要负责人；
  - ②劳动者姓名、住址和居民身份证号码；
  - ③劳动合同期限（固定/无固定/以完成一定工作任务为期限）；
  - ④工作内容和工作地点（【高危】"工作地点：全国/公司安排"过宽条款——司法实践多要求相对具体，调动权滥用易被认定无效或构成违约）；
  - ⑤工作时间和休息休假（标准工时/综合计算工时/不定时——后两种需经劳动行政部门批准方可执行，合同只约定不报批的条款高危）；
  - ⑥劳动报酬（金额、结构、支付日期；约定"按公司薪酬制度执行"而不写数额——举证风险在单位）；
  - ⑦社会保险（五险为强制，不得约定排除）；
  - ⑧劳动保护、劳动条件和职业危害防护；
  - ⑨法律法规规定应当纳入的其他事项。
  - 可备条款：试用期、培训、保密、补充保险、福利待遇、违约责任（受限，见下）。
- [ ] **试用期规则**（劳动合同法第19/20/21/70/83条）【高危】
  - 期限上限：合同期3个月以上不满1年 → ≤1个月；1年以上不满3年 → ≤2个月；3年以上固定期限及无固定期限 → ≤6个月。
  - 不得约定试用期：以完成一定工作任务为期限的合同；合同期不满3个月；非全日制用工。
  - 同一用人单位与同一劳动者只能约定一次试用期（续签、调岗、再次入职均不得重新约定）。
  - 试用期包含在劳动合同期限内；仅约定试用期的（"试用期协议"单独成文），试用期不成立，该期限视为劳动合同期限。
  - 工资下限：不得低于本单位相同岗位最低档工资的80%或劳动合同约定工资的80%，且不得低于当地最低工资标准（第20条 +《劳动合同法实施条例》第15条）。
  - 解除限制：试用期内单位解除须证明劳动者"不符合录用条件"（第39条第1项）——审查合同是否明确约定录用条件，否则解除高危。
  - 违法约定试用期且已履行的：以试用期满月工资为标准，按已履行的超期期间支付赔偿金（第83条）。
  - 【高危红旗】试用期超过法定上限、试用期不缴社保、试用期工资打5-7折、试用期单独协议、"试岗7天无薪"（=事实用工应付工资）。

## 3. 违约金限制、服务期、竞业限制、保密

- [ ] **违约金条款合法性总开关**（劳动合同法第22/23/25条）【效力】
  - 原则：用人单位不得与劳动者约定由劳动者承担违约金（第25条）。
  - 例外一（服务期，第22条）：单位为劳动者提供**专项培训费用**进行专业技术培训的，可约定服务期；违约金数额不得超过单位提供的培训费用，且要求支付的违约金不得超过服务期尚未履行部分所应分摊的培训费用。
    - 审查点：培训费用凭证（学费、差旅、住宿等实际支出，须有票据）；普通入职培训/上岗培训不能约定服务期；服务期与合同期关系（合同期届满服务期未届满的顺延至服务期满，除非另有约定，《实施条例》第17条）。
    - 劳动者依第38条（单位过错）解除的不属违反服务期，不付违约金；劳动者因严重违纪等被解除的仍须付违约金（《实施条例》第26条）。
  - 例外二（竞业限制违约金，第23条）：见下。
  - 【高危红旗】"提前离职赔偿X万元""未满合同期扣押金/服装费/培训费（无专项培训）""违约金=全部工资"——一律无效；扣押证件、收取财物违反第9条。
- [ ] **竞业限制协议**（劳动合同法第23/24/90条 +《劳争解释一》《劳争解释二》）
  - 人员范围：限于高级管理人员、高级技术人员和其他负有保密义务的人员（第24条）。
    - 新规则（《劳争解释二》）：劳动者未知悉、接触商业秘密和与知识产权相关保密事项的，竞业限制条款不生效，对劳动者无约束力；约定的范围、地域、期限与所知悉接触的保密事项不相适应的，超过部分无效。→ 审查"全员竞业"协议直接报警。
  - 期限：解除/终止后不得超过2年，超过部分无效（第24条第2款）。
  - 经济补偿：须在解除/终止后竞业限制期限内按月给予（第23条）。
    - 未约定补偿标准：劳动者已履行竞业限制义务的，可要求按劳动合同解除/终止前12个月平均工资的30%按月支付，低于当地最低工资的按最低工资（《劳争解释一》第36条）。
    - 单位原因3个月未支付补偿的，劳动者可请求解除竞业限制约定（《劳争解释一》第38条）。
    - 单位请求解除竞业限制协议的，劳动者可请求额外支付3个月补偿（《劳争解释一》第39条）。
    - 劳动者违反竞业限制支付违约金后，单位要求其继续履行的，法院支持（《劳争解释一》第40条）。
  - 审查点：①范围/地域是否具体可执行（"全球""所有行业"过宽）；②补偿金额与违约金是否匹配（补偿畸低+违约金畸高，酌减风险）；③在职期间竞业义务与补偿是否混同于工资（应单独列示）；④违约金畸高部分可依民法典第585条酌减；⑤报告义务（就业情况定期申报）条款。
- [ ] **保密协议**
  - 保密义务不以支付保密费为前提（忠实义务），但建议明确商业秘密范围（技术信息+经营信息，对照《反不正当竞争法》第9条商业秘密定义：不为公众所知悉、具有商业价值、经权利人采取相应保密措施）。
  - 审查点：保密期限（在职+离职后合理期间）；保密信息定义与例外（公知信息、合法获得信息）；载体返还/销毁义务；违约责任（保密义务违约金约定是否落入第25条限制——单纯保密义务违约金司法实践分歧大，稳妥做法是与竞业限制/损失赔偿挂钩，第90条损失赔偿责任兜底）。
  - 与竞业限制的关系：保密义务≠竞业限制；仅签保密协议不产生择业限制和经济补偿义务。

## 4. 社会保险与住房公积金

- [ ] **社保条款**【效力】【高危】
  - 缴纳社保是双方法定义务（《劳动法》第72条；《社会保险法》第58条：自用工之日起30日内办理社保登记；第60条：单位代扣代缴）。
  - 效力规则（《劳争解释二》第19条，2025-09-01起）：用人单位与劳动者**约定**或劳动者**承诺**无需缴纳社保的，约定/承诺无效；单位未依法缴纳，劳动者依劳动合同法第38条第3项解除合同并主张经济补偿的，法院支持；单位补缴后可请求劳动者返还已支付的"社保补贴"。
  - 【高危红旗清单】（命中即标无效+补偿风险）：
    ① "自愿放弃社保声明/承诺书"；
    ② "以社保补贴形式发放现金，员工自行参保"；
    ③ "试用期不缴社保，转正后补缴"；
    ④ "按最低基数缴纳"（低于实际工资基数→行政稽核补缴+滞纳金风险，《社会保险法》第86条：按日万分之五滞纳金，逾期不缴处欠缴数额1-3倍罚款）；
    ⑤ "在异地/挂靠第三方代缴社保"（与劳动关系主体分离，工伤认定、待遇申领障碍）。
  - 商业保险不能替代社会保险；补充商业险（雇主责任险等）作为增配条款审查保额与受益人。
- [ ] **住房公积金**
  - 强制缴存（《住房公积金管理条例》：单位应当按时足额缴存，不得逾期或少缴）；"自愿放弃公积金"约定同样无效风险。
  - 审查点：缴存基数（上年度月平均工资）与比例（5%-12%区间按当地规定）；入职当月/次月起缴；与工资基数一致性。

## 5. 劳务派遣与劳务外包（假外包真派遣）

- [ ] **劳务派遣协议审查**（劳动合同法第57-67条 +《劳务派遣暂行规定》人社部令第22号）
  - 派遣单位资质：注册资本≥200万元、取得劳务派遣行政许可（第57条）。
  - 三性岗位限制（第66条）：临时性（存续≤6个月）、辅助性（为主营业务提供服务的非主营业务岗位，须经民主程序+公示）、替代性（员工脱产学习/休假等替代）；劳务派遣是补充用工形式。
  - 比例红线：用工单位使用的被派遣劳动者数量不得超过其用工总量的10%（《暂行规定》第4条）。
  - 派遣单位义务：与被派遣劳动者订立2年以上固定期限劳动合同、按月付酬、无工作期间按最低工资支付（第58条）；跨地区派遣按用工单位所在地标准参保（《暂行规定》第18条）。
  - 用工单位义务：同工同酬（第63条）；加班、绩效、福利；不得再派遣；退回机制仅限法定情形。
  - 【高危红旗】派遣协议中"工伤/欠薪责任全部由派遣单位承担、用工单位概不负责"——对劳动者不生效，用工单位连带赔偿责任（第92条：给被派遣劳动者造成损害的，派遣单位与用工单位承担连带赔偿责任）。
- [ ] **劳务外包协议审查（假外包真派遣识别）**【高危】
  - 区分核心：外包购买的是"工作成果/服务"，派遣购买的是"劳动力/人的使用"。
  - 认定规则：《劳务派遣暂行规定》第27条——用人单位以承揽、外包等名义，按劳务派遣用工形式使用劳动者的，按本规定处理（即穿透认定）。
  - 穿透识别信号（命中≥2项重点标注）：
    ① 外包人员由发包方直接考勤、排班、指挥、考核、奖惩；
    ② 外包费按"人头×单价"结算而非按工作量/成果；
    ③ 外包人员与发包方员工混岗作业、使用发包方系统工位门禁；
    ④ 外包单位仅收管理费，不承担业务风险与成果责任；
    ⑤ 发包方直接向外包人员发放报酬或补贴。
  - 真外包协议必备：成果交付与验收标准；外包方独立管理其员工的承诺与事实保证（自行考勤、发放工资、缴纳社保）；按成果计价结算；外包方用工资质与工伤保险责任；数据安全与保密；发包方对外的隔离条款（不与外包人员建立任何直接用工管理关系）。

## 6. 解除与终止：经济补偿计算（N / N+1 / 2N）

- [ ] **协商解除协议审查**
  - 解除原因表述（单位提出 vs 个人原因——决定经济补偿义务，第46条：单位提出协商一致解除应付N；劳动者主动辞职无补偿）。
  - 补偿金额是否覆盖法定下限（N），明确为"一次性了结全部争议"的兜底条款效力（劳动者主张显失公平的撤销风险，建议列明补偿构成明细：经济补偿、工资、加班费、未休年假折算、社保补缴安排等分别列示）。
  - 离职交接、竞业限制启动/解除确认、保密义务重申、证明与档案社保转移时限（单位应在15日内办理档案和社保转移，第50条）。
  - 【高危红旗】"放弃一切权利、不得仲裁诉讼"绝对弃权条款——仲裁诉讼权利不可预先放弃，条款无效风险，建议改为具体的权利义务结清确认。
- [ ] **经济补偿 N**（第46/47条）
  - 适用情形（第46条）：劳动者依第38条被迫解除；单位提出协商一致解除；单位依第40条（无过失性辞退）、第41条（经济性裁员）解除；固定期限合同到期单位不续签或降低条件续签被拒；单位破产、吊销执照、解散等终止；法律法规其他情形。
  - 计算（第47条）：每满1年支付1个月工资；6个月以上不满1年按1年；不满6个月支付半个月工资。月工资=解除/终止前12个月平均应得工资（含计时计件工资、奖金、津贴补贴等货币性收入，《实施条例》第27条）；低于当地最低工资按最低工资。
  - 封顶：月工资高于当地上年度职工月平均工资3倍的，按3倍封顶且年限最高12年。
- [ ] **N+1（代通知金）**（第40条）
  - 仅三种情形：①医疗期满后不能从事原工作也不能从事另行安排工作；②不能胜任工作经培训或调岗仍不能胜任；③客观情况重大变化致合同无法履行且协商不成。
  - 单位提前30日书面通知 **或** 额外支付1个月工资（"代通知金"，按上一个月工资标准）。
  - 【提示】协商一致解除、到期不续签、过失性辞退均无"+1"；"+1"与N性质不同、并行适用。
- [ ] **2N（赔偿金）**（第48/87条）
  - 单位违法解除/终止（无法定事由、程序违法如未通知工会第43条、解除禁止解除对象如三期女职工/医疗期内/工伤停工留薪期等第42条情形）→ 按经济补偿标准2倍支付赔偿金；劳动者要求继续履行且能履行的，应继续履行（第48条）。
  - 赔偿金与经济补偿不并罚（《实施条例》第25条）；赔偿金年限自用工之日起算。
- [ ] **合同到期与无固定期限合同**（第14条）
  - 连续订立二次固定期限合同后续订的，劳动者提出或同意续订的，除劳动者提出订固定期限外，应订无固定期限合同；《劳争解释二》进一步明确"连续订立二次"的认定口径，堵规避操作（如通过关联主体轮换签约、自动顺延条款等）。
  - 【高危红旗】"本合同到期自动终止，单位无需支付任何补偿"——单位不续签仍应付N；"合同期满自动顺延X年"条款可能被视为规避无固定期限合同义务。
- [ ] **解除程序合规清单**
  - 过失性辞退（第39条）：试用期不符合录用条件（须有明确录用条件+考核证据）、严重违反规章制度（制度须经民主程序制定并公示告知，第4条——审查合同是否援引未公示的制度）、严重失职营私舞弊造成重大损害、双重劳动关系拒不改正、欺诈订立、被追究刑事责任。
  - 程序：事先将理由通知工会（第43条）；送达解除通知；出具解除/终止证明（第50条，不出具造成损失的第89条赔偿责任）。
  - 年终奖/提成"发放日在职才支付"条款——司法实践不一，审查时提示按在职期间比例结算的折中写法。
